#+title: multi-ghostel
#+author: bismigel
#+email: bismigel@pm.me

A [[https://github.com/dakra/ghostel][ghostel]] port of
[[https://github.com/suonlight/multi-vterm][multi-vterm]].

Most of multi-vterm already ships with ghostel, so this package only adds
what is missing: directory-scoped reuse, an always-new terminal command,
and a togglable dedicated window.

* Commands
| Command                          | Suggested key | Description                                              |
|----------------------------------+---------------+----------------------------------------------------------|
| =multi-ghostel=                  | =C-c T=       | Always start a new session here.                         |
| =multi-ghostel-cwd=              | =C-c t=       | Reuse the terminal for this directory, else create one. *Preferred.* |
| =multi-ghostel-dedicated-toggle= | =C-`=         | Show/hide the dedicated terminal window.                 |
| =multi-ghostel-dedicated-open=   |               | Open it (creating the terminal if needed).               |
| =multi-ghostel-dedicated-close=  |               | Close it; the terminal keeps running.                    |
| =multi-ghostel-dedicated-select= |               | Focus it.                                                |

=multi-ghostel-cwd= keys off =default-directory= (so it follows =cd= via
OSC 7), giving one reusable terminal per directory.  It is the author's
preferred behavior and is not a multi-vterm port.  =multi-ghostel= is the
port of =multi-vterm= (always a fresh session), since plain =ghostel=
/reuses/ its buffer and keeps that terminal's directory.

* Installation
#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/multi-ghostel")
(require 'multi-ghostel)
(global-set-key (kbd "C-c t") #'multi-ghostel-cwd)
(global-set-key (kbd "C-c T") #'multi-ghostel)
(global-set-key (kbd "C-`")   #'multi-ghostel-dedicated-toggle)
#+end_src

* Naming
=multi-ghostel-cwd= does not name buffers itself; naming is ghostel's job:

#+begin_src emacs-lisp
(setq ghostel-buffer-name-function #'ghostel-buffer-name-by-directory)
#+end_src

This names /and/ keeps syncing every ghostel buffer to its directory (it is
global, not limited to =multi-ghostel-cwd=).

* Customization
- =multi-ghostel-dedicated-window-height= — lines (default 30).
- =multi-ghostel-dedicated-window-height-percent= — percent, clamped 10–90;
  overrides the line height when non-nil.
- =multi-ghostel-dedicated-buffer-name= — default ="*ghostel - dedicated*=".

* Port map
Dropped as redundant (ghostel provides an equivalent):

| multi-vterm                   | ghostel                                             |
|-------------------------------+-----------------------------------------------------|
| =multi-vterm-project=         | =ghostel-project=                                   |
| =multi-vterm-next=, =multi-vterm-prev= | =ghostel-next=, =ghostel-previous=          |
| =multi-vterm-get-buffer=      | =ghostel-create=                                    |
| =multi-vterm-handle-close=    | =ghostel-kill-buffer-on-exit=                       |
| =multi-vterm-rename-buffer=   | =rename-buffer= / =ghostel-buffer-name-function=    |
| =multi-vterm-shell-name=      | =ghostel-shell=                                     |
| =multi-vterm-program=         | =ghostel-shell=                                     |
| =multi-vterm-buffer-name=     | =ghostel-buffer-name=                               |
| =multi-vterm-buffer-list=     | =ghostel-buffer-list=                               |
| =multi-vterm-switch=          | =ghostel-next=, =ghostel-previous=                  |

Ported: the dedicated-window commands, their height customization, and the
window/buffer existence helpers.  Added: =multi-ghostel-cwd= (reuse by
directory), =multi-ghostel= (always-new), and
=multi-ghostel-dedicated-get-buffer=.
